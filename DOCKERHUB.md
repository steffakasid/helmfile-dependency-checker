# Helmfile Dependency Checker

Helmfile Dependency Checker (HDC) is a CLI tool that checks Helm chart dependencies declared in helmfiles.

It verifies if chart versions are up to date and whether chart releases are still actively maintained.

## Highlights

- Works with `helmfile.yaml` and `helmfile.d/*.yaml`
- No local Helm or helmfile binaries required
- Outputs results as Markdown, JSON, or HTML
- Uses CI-friendly exit codes
